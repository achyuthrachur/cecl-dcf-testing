## 1. PROJECT OVERVIEW

This project implements a CECL (Current Expected Credit Loss) DCF (Discounted Cash Flow) calculation engine in TypeScript that replicates the calculations performed in an Excel template and Abrigo software for loan reserve calculations.

### Purpose
- Validate Abrigo's CECL reserve calculations by replicating them independently
- Process loan data extracted from screenshots
- Compare calculated reserves against Abrigo's reported values
- Identify and minimize variances

## 2. RECENT FIX IMPLEMENTED (January 29, 2026)

### Problem
Loan 2310074014 (and other loans using "360 Days" or "30/360" day count conventions) had ~18% variance.

### Root Cause
The **amortization multiplier** was not being applied correctly for "30/360" and "360 Days" conventions.

**Excel Formula (Cell J3)**:
```excel
=IF(ISNUMBER(SEARCH("360",C7)),365/360,1)
```

This means ANY day count convention containing "360" should use the 365/360 multiplier:
- "Actual 360" → 365/360 ✓ (was correct)
- "30/360" → 365/360 ✗ (was returning 1 - FIXED)
- "360 Days" → 365/360 ✗ (was returning 1 - FIXED)
- "Actual 365" → 1 ✓ (was correct)

### Fix Applied

**File**: `src/lib/calculation-engine.ts`

1. **`getAmortizationMultiplier()` (lines 214-224)**:
```typescript
export function getAmortizationMultiplier(amortizationDays: AmortizationDays): number {
  if (amortizationDays === 'Actual 360' ||
      amortizationDays === '30/360' ||
      amortizationDays === '360 Days') {
    return 365 / 360;
  }
  return 1;
}
```

2. **`calculateMonthlyInterestRate()` (lines 239-264)**:
```typescript
case '30/360':
case '360 Days':
  // rate × (365/360) × (1/12)
  return annualRate * (365 / 360) / 12;
```

### Additional Fix for Loan 2310074014
The loan also needed `reamortize: true` and `amortizationTerm: 337` to match Excel's "Reamortize Each Period: Yes" setting.

## 4. DCF CALCULATION METHODOLOGY

### Key Formulas (Per Excel Template)

#### Amortization Multiplier
```
IF(SEARCH("360", AmortizationDays), 365/360, 1)
```

#### Monthly Interest Rate
```
InterestRate × AmortizationMultiplier × IF(SEARCH("Actual"), DaysInMonth/365, 1/12)
```

#### Rate Conversion (Annual to Monthly)
```
MonthlyRate = 1 - (1 - AnnualRate)^(1/12)
```
(Compound decompounding formula, rounded to 6 decimals)

#### Present Value
```
PV = CashFlow / (1 + EffectiveYield)^(IF(SEARCH("Actual"), CumulativeDays/365, Period/12))
```

#### Reserve
```
Reserve = BookBalance + UnamortizedAmount - NPV
```

### Processing Order Per Period
1. Interest on beginning balance
2. Principal payment (varies by loan type)
3. Prepayments (capped at balance - principal)
4. Defaults (capped at balance - principal - prepayments)
5. Recovery scheduling (delayed by recoveryDelay months)
6. Ending balance calculation
7. Cash flow aggregation
8. Present value discounting

### Loan Types Supported
- **Fixed Payment** - Standard amortizing with optional reamortization
- **Fixed Principal** - Fixed principal amount per period
- **Interest Only** - Principal via curtailment rate only
- **Line of Credit** - No prepayments, uses curtailment

### Period Calculation
```
totalPeriods = contractualPeriods + recoveryDelay - 1
contractualPeriods = totalPeriods - recoveryDelay + 1
```

### Recovery Delay
Default: 12 months. Recoveries from defaults are delayed and appear in the "tail" periods after maturity.
